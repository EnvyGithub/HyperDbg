# Security Policy

This repository is a personal research fork of
[HyperDbg/HyperDbg](https://github.com/HyperDbg/HyperDbg).

## Reporting

Before reporting an issue, determine whether it also exists in the upstream
project.

- If the issue is present in upstream HyperDbg, follow the upstream project's
  reporting process.
- If the issue is specific to changes in this fork, please avoid publishing
  sensitive exploit details in a public issue. Use a private contact channel
  associated with this GitHub account where possible, or open a minimal issue
  that contains no exploit details so a private follow-up can be arranged.

## Research scope

Work in this fork is intended for debugging, compatibility work, defensive
analysis, and vulnerability validation on systems and software that the
researcher owns or is authorized to test.

The presence of debugging, tracing, hooking, virtualization, or reverse-
engineering functionality does not imply authorization to analyze third-party
systems without permission.

## Attribution

Upstream security fixes and upstream project behavior remain attributable to
their original authors. See [FORK_NOTES.md](FORK_NOTES.md) for guidance on
distinguishing upstream work from downstream experiments.
